# 🛡️ SafeHer - AI Women Safety System

An AI-powered women safety system with voice-activated emergency alerts, real-time location tracking, and automatic notifications to guardians, police, and NGOs.

![Python](https://img.shields.io/badge/Python-3.13-blue)
![Flask](https://img.shields.io/badge/Flask-2.3.2-green)
![License](https://img.shields.io/badge/License-MIT-yellow)

---

## ✨ Features

- 🎤 **Multi-Language Voice Detection** - Detects "help", "bachao", "madad" in Hindi & English
- 📍 **Real-time Location Tracking** - Live GPS tracking with interactive maps
- 🚨 **Automatic Emergency Alerts** - Notifies guardians, nearby police & NGOs
- 📱 **Shake Detection** - Emergency trigger by shaking phone 3 times
- 🤖 **AI Safety Prediction** - Decision Tree ML model for area risk assessment
- 👨‍👩‍👧 **Guardian Network** - Multiple guardians can monitor a user
- 📊 **Admin Analytics** - Dashboard with charts and user management
- 🔐 **Secure Authentication** - Password hashing with Werkzeug
- ⏱️ **10-Second Countdown** - Prevents false alarms
